# Домашние церкви Ижевска

Рабочий MVP Telegram-бота + Telegram Mini App для поиска домашних церквей.

## Уже реализовано

- `/start` и главное меню Telegram-бота
- список домашних церквей
- фильтр по районам
- карточка домашней церкви
- кнопка «Хочу присоединиться»
- уведомление администратору о заявке (если задан `ADMIN_CHAT_ID`)
- кнопка связи с лидером
- Яндекс.Маршрут до места встречи
- Telegram Mini App по адресу `/app`
- реальная карта OpenStreetMap
- точки домашних церквей на карте
- список и фильтр по району
- «Показать ближайшие ко мне» через геолокацию браузера
- API `/api/churches` и `/api/requests`
- health check `/health` для Render

Все данные домашних церквей сейчас тестовые и находятся в `bot/data.py`.

## Render

Build Command:

```bash
pip install -r requirements.txt
```

Start Command:

```bash
python bot/main.py
```

Python фиксируется через `.python-version`.

## Переменные окружения

Обязательно:

```text
BOT_TOKEN=<токен от BotFather>
```

Рекомендуется:

```text
ADMIN_CHAT_ID=<Telegram ID администратора>
WEB_APP_URL=<публичный HTTPS URL сервиса Render>
```

Если Render предоставляет `RENDER_EXTERNAL_URL`, бот попробует использовать его автоматически.

## Mini App

После деплоя откройте:

```text
https://<ваш-render-домен>/app
```

Если `WEB_APP_URL` или `RENDER_EXTERNAL_URL` доступен приложению, в `/start` автоматически появится кнопка «Открыть карту и каталог».

## Важно перед реальным запуском

- заменить тестовые адреса, лидеров и Telegram username в `bot/data.py`;
- заменить тестовые координаты на реальные;
- подключить постоянную базу PostgreSQL вместо временного хранения заявок в памяти;
- добавить реальные фото групп и лидеров.
